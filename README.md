# Amazon-E-Commerce-Sales-Data-Analysis

Quick end-to-end data project on Amazon sales data. Cleaned and preprocessed the raw dataset using Python, built a quick machine learning baseline for trend forecasting, and created a interactive dashboard in Power BI.


#What I Did

1 Data Cleaning (Python & Pandas):
   Fixed missing values in dates, quantities, and category columns. Standardized data types and exported the clean dataset (ecommerce_cleaned.csv).

2 Trend Forecasting (Scikit-Learn):
   Used a basic Linear Regression model on monthly sales data to check overall sales direction and forecasts.

3 Power BI Dashboard:
   Tracked main metrics like Total Sales, Orders, Average Order Value, and top-selling product categories with interactive filters.

 Files Included
* Amazon Sale Report.csv — Raw data
* ecommerce_cleaned.csv — Cleaned dataset
* data_cleaning.ipynb — Python cleaning & modeling script
* Amazon_Sales_Dashboard.pbix — Power BI file
* Amazon_Sales_Dashboard.pdf — PDF export of the dashboard
